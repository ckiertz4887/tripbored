## New Game Mechanics & Features

- Ability to lock the game (for passing the device between people)
- "Finalize" a game
- Shared games — multiple people sharing one board
- Versus games — multiple cars/teams competing
- Bonus-game card persistence: if bonus games are active, shared cards should persist across games and should NOT be double-scored
- Per-user tallies AND a universal/whole-game tally; ability to name each game, either during play or at finalization
- Stats + insights for users
- Undo / redo
- Full history of all card taps, including untaps (in case of accidental taps)
- Area for users to submit suggestions

- Search functionality
- Car color category should show an actual color swatch
- Link to state DMV pages with real plate images (reference feature)
- Taptic/tap-target fix: scrolling should never register as a card tap
- Feature photo for the main game/trip, to remember it by
- After finalizing a game, generate a branded, social-media-friendly share card with highlights and stats from the round

Ask users for starting state and destination state, apply a basic formula. Explicit note: *"I don't want to do this just yet, just jotting down my thoughts."*
2. Emergency responders re-scored: lights off = 5 flat (all three types), lights and/or sirens on = 10 flat (all three types), car pulled over by police = 10.

4. Global point rule: every point value should be either 1 or a multiple of 5 — no 2s, 3s, 4s, 6s, 7s, 8s, 9s, 12s, 16s, etc.
